# Axiom Protection Systems

A responsive front-end website for a fictional British protective
equipment manufacturer.

Axiom Protection Systems was created as an educational web development
project to demonstrate HTML, CSS, JavaScript and responsive design
without relying on a database or back-end service.

## Live Project

https://sandersondigital.uk/Axiom-Protection-Systems/

## The Project

The website presents a fictional modular armour carrier system called
the ACS-1 Adaptive Carrier System.

The main interactive element is a product configurator that allows the
user to select different carrier components and accessories. JavaScript
then calculates an indicative package price from the selected options.

## Features

- Responsive desktop, tablet and mobile layouts
- HTML5 semantic structure
- Custom CSS styling
- JavaScript product configurator
- Input validation
- Dynamic price calculation
- External image attribution
- No database or back end

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages
